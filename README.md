# trajectory-time

沿几何路径的时间最优速度规划（仅 Go 标准库）：给定折线路径与速度 / 加速度 / jerk 限制，
计算随时间变化的速度曲线（梯形或 S 曲线），验证约束满足情况，并生成单一静态 HTML
报告（原生 HTML/CSS/JavaScript，无任何框架与图形库）展示曲线并逐帧回放运动过程。

## 构建与运行

```sh
go test ./...          # 运行全部自动化测试
go run ./cmd/plan      # 生成 report.html（可用 -o 指定输出，-dt 指定采样周期）
open report.html       # 浏览器打开，无需任何服务
```

## 模型

### 梯形速度曲线（`PlanTrapezoid`）

分段恒定加速度：加速段 → 匀速段 → 减速段。给定距离 `L`、边界速度 `v0/v1`、
限速 `Vmax` 与加速度限幅 `Amax`：

- 若加速到 `Vmax` 再减速到 `v1` 所需距离 `d_up + d_down ≤ L`，输出标准梯形，
  匀速段时长 `(L - d_up - d_down) / Vmax`；
- 否则**退化为三角形曲线**：峰值速度
  `vp = sqrt((2·Amax·L + v0² + v1²)/2) < Vmax`，无匀速段。
  规划器只发射时长为正的段，绝不会输出负的匀速段时长；
- 若距离连 `v0 → v1` 都无法衔接（`L < |v1² - v0²| / (2·Amax)`），返回
  `ErrInfeasible` —— 这就是约束耦合下的可行性判断。

### S 曲线（`PlanSCurve`）

分段恒定 jerk，最多七段：`+j, 恒加速, -j, 匀速, -j, 恒减速, +j`。
加速度由 jerk 积分得到，因此在所有段切换处**加速度天然连续**。

两种退化被显式处理：

1. **短路径**：限速不可达，匀速段消失，峰值速度解析求解
   （`Amax` 可达时为二次方程，不可达时 `vp = (L·√Jmax / 2)^(2/3)`）；
2. **极端限制组合**：当峰值速度 `vp < Amax²/Jmax` 时，jerk 限制使加速度
   永远达不到 `Amax`，恒定加速度段退化为零长度并被**识别并跳过**
   （`rampTimes` 返回 `ta = 0`，`push` 丢弃非正时长的段），
   不会产生非法的负时长段。

### 分段拼接（`PlanPath`）

路径为折线，每个直线段以零边界速度独立规划（在拐角处停车），再按时间与
弧长拼接。因此拼接处位置、速度连续；S 曲线模型下拼接处加速度也为零、连续。

## 约束验证（`Validate`）

对采样轨迹逐点检查：速度不超过 `Vmax`、加速度幅值不超过 `Amax`；
jerk 通过对加速度采样做有限差分检查（这同时能发现拼接处的加速度跳变——
跳变会表现为巨大的差分 jerk）。每个违例报告**时刻、采样索引、约束类型、
实测值与限幅**。梯形曲线加速度本就分段恒定（边界处跳变是模型固有特性），
对其应令 `checkJerk = false`。

## 测试覆盖（`planner/planner_test.go`）

- 梯形曲线在限速可达（含匀速段）与不可达（退化为三角形）两种情形下的
  总时长、峰值速度、覆盖距离与约束满足；
- 不可行边界条件返回 `ErrInfeasible`；
- S 曲线完整七段、恒加速段退化（`ta = 0`）、匀速段退化三种情形，
  总时长与理论最优值一致；
- 人为注入速度 / 加速度 / 加速度跳变违例，验证器能定位到具体时刻与约束类型；
- 多段路径拼接后位置 / 速度 / 加速度（S 曲线）连续且无约束违例；
- 不同限制与距离的组合扫描：永不产生非正时长段、精确覆盖距离、不违反约束。

## 已知局限

- 拐角处必须停车（各段边界速度固定为零）；不支持非零拐角速度或
  基于曲率的速度规划，因此不是全局时间最优，而是分段时间最优。
- 路径为折线，未做几何平滑（无圆弧 / 样条过渡）。
- 梯形模型的加速度在段边界不连续（jerk 无穷大），这是模型固有特性；
  需要加速度连续的场合请使用 S 曲线模型。
- 验证器基于均匀采样做有限差分，采样周期之外、恰好落在采样点之间的
  瞬时违例无法保证被发现；采样器会跳过边界处过小的步长以避免差分噪声。
